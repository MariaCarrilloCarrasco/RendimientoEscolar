# Iniciativas y emprendimiento

Web personal de María Carrillo Carrasco para presentar su perfil profesional, su currículum y sus iniciativas sociales y emprendedoras.

## Contenido previsto

- Video de presentación reutilizado del [videocurrículum original](https://mariacarrillocarrasco.github.io/Portfolio-Videocurr-culum---Mar-a-Carrillo-Carrasco/#video).
- Un segundo video animado de presentación, pendiente de incorporar cuando esté disponible el archivo o su enlace.
- Acceso para consultar o descargar el [currículum en PDF](https://mariacarrillocarrasco.github.io/Portfolio-Videocurr-culum---Mar-a-Carrillo-Carrasco/CV_Maria_Carrillo.pdf).
- Fotografías de los negocios e iniciativas que se quieran destacar. Las imágenes y los nombres de cada iniciativa están pendientes de confirmar.

La referencia también muestra un proyecto de apoyo digital a personas mayores con tres imágenes: un folleto informativo, una fotografía de María y una tarjeta de visita. Se podrán incluir si forman parte de los negocios o iniciativas que se presenten.

## Tecnologías

El proyecto está planteado como una web estática con HTML, CSS y JavaScript, sin dependencias de instalación.

## Archivos

- `index.html`: estructura y contenido de la página.
- `style.css`: estilos y adaptación a móvil y escritorio.
- `javascript.js`: interacciones de la página.

## Vista local

Abre `index.html` directamente en el navegador. También puedes iniciar un servidor local desde esta carpeta:

```bash
python -m http.server 8000
```

Después, visita <http://localhost:8000>.
