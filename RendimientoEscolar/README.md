# Rendimiento Escolar

Una pequeña aplicación web para estudiar con enfoque, control del tiempo y seguimiento semanal. Incluye temporizador tipo Pomodoro, objetivos de estudio, plan semanal, racha de días, personalización visual y soporte multilenguaje.

## Características

- Temporizador Pomodoro con modo de descanso
- Modo TDAH para tiempos más cortos
- Modo de lenguaje de signos
- Objetivo de estudio editable
- Dictado por voz y lectura en voz alta
- Calendario semanal de tiempo estudiado
- Racha de días consecutivos
- Personalización de colores y tamaño de letra
- Soporte de varios idiomas
- Diseño responsivo y moderno

## Tecnologías

- HTML
- CSS
- JavaScript
- Font Awesome
- Canvas Confetti

## Cómo abrir la app

1. Abre la carpeta del proyecto.
2. Haz doble clic en `index.html`.
3. La aplicación se ejecutará en el navegador.

También puedes servirla con un servidor local si prefieres, por ejemplo:

```bash
python -m http.server 8000
```

Luego entra en:

```text
http://localhost:8000
```

## Funciones principales

### Temporizador
- Ajusta tiempos de estudio y descanso
- Permite iniciar, pausar y reiniciar
- Muestra el tiempo restante en pantalla

### Objetivo de estudio
- Escribe tus metas personales
- Usa pictogramas rápidos
- Habilita dictado por voz

### Seguimiento
- Guarda el tiempo semanal trabajado
- Muestra una racha de días consecutivos
- Permite ver el progreso a lo largo de la semana

### Accesibilidad
- Modo TDAH
- Modo de lenguaje de signos
- Lectura del contenido en voz alta
- Personalización visual para mejorar la experiencia

## Personalización

La interfaz incluye un panel lateral para cambiar:

- color de fondo
- color de texto
- color de botones
- tamaño de letra
- reinicio rápido de la configuración
